# c6s feedback

This is the public feedback and support tracker for
[c6s — Cerberus](https://c6s.app).

Use the issue forms to:

- report a reproducible product bug;
- suggest a feature or workflow improvement; or
- ask for help with installation and account access.

Before opening an issue, search existing reports and check the
[documentation](https://docs.c6s.app). Include the app or CLI version,
platform, release channel, and non-sensitive diagnostic details when relevant.

## Never post secrets

Do not include passwords, API keys, tokens, private keys, recovery material, vault
exports, unredacted logs, or personal data. For a suspected vulnerability, stop and
follow the private process in the [security policy](https://github.com/c6shq/.github/blob/main/SECURITY.md).

Product source repositories remain private during the beta. This tracker contains no
application source code.
